# 实验：policy 与 secrets 生命周期运维

本实验将把第 5.3 节的两个管理平面放到同一个工作流中：`vault secrets ...` 管理机密引擎挂载点，`vault policy ...` 管理访问策略。

你将完成五项任务：

1. 盘点当前策略和机密引擎，并启用一个教学用 KV v2 挂载点。
2. 调整挂载点配置，执行一次路径迁移，并观察禁用临时挂载点的结果。
3. 编写本地策略文件，使用 `policy fmt` 格式化后上传到 Vault。
4. 创建受限 token，验证策略授予的读取能力和拒绝的写入能力。
5. 删除策略并禁用机密引擎，观察访问能力和挂载点生命周期如何结束。

所有命令都在临时 dev server 中执行。请不要把本实验里的 root token、明文密码或销毁性操作照搬到生产环境。
