# 恭喜完成实验！

你已经在真实 Vault dev server 上完成了五个通用 CRUD 命令的核心练习。

## 本实验的核心收获

| 阶段 | 你亲手验证的事实 |
| :--- | :--- |
| `read` | 路径是 Vault API 入口，输出可以切换为 table/json/field |
| `list` | 列出路径下的 key，不读取 key 的值 |
| `write` | 支持 `key=value`、`@file`、`key=-`、stdin JSON 与 `-force` |
| `delete` | CLI 发出删除动作，后端决定删除规则和安全前提 |
| `patch` | 只更新指定字段，适合小范围修改配置对象 |

## 关键心智模型

```text
CLI 动词 + API 路径 + 输入参数
        ↓
Vault 路由表
        ↓
挂载在该路径上的后端引擎决定真实语义
```

下一节继续学习认证、令牌和生命周期相关命令时，你会反复用到这个模型：先看路径，再看动词，最后看后端文档。
